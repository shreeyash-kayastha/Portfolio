# Public Assets Folder

Place static assets here:

## Directory Structure
```
public/
├── assets/
│   ├── Shreeyash_Kayastha_CV.pdf    # Your CV/Resume PDF
│   ├── project-nepse.svg            # Project visualizations
│   ├── project-placeholder.svg      # Placeholder for other projects
│   └── ...
└── favicon.ico                      # Website favicon
```

## Notes

- Images and PDFs in this folder are served statically
- Update file paths in `src/data/portfolio.js` when adding files
- Optimize images before adding them (use tools like TinyPNG)
- SVG files are preferred for icons and graphics (scalable, small file size)
